# Dark Souls II: The Completionist’s Handbook

**Scholar of the First Sin — Version 1.1**

An unofficial, non-commercial completionist handbook created by **AsianMop** for *Dark Souls II: Scholar of the First Sin*.

Version **1.1** supersedes Version **1.0** and represents the first fully publication-audited edition of the handbook. Every chapter, appendix and supporting publication section has undergone comprehensive editorial verification against multiple *Scholar of the First Sin* references.

The handbook provides a complete, route-ordered journey through the base game and all three Crown DLC campaigns, including collectibles, NPC and merchant progression, boss strategies, summons, invasions, Scholar-specific differences, completion traps, post-game cleanup and Journey 2 preparation.

## Interactive All-Items Checklist

[**Download the Scholar-Verified Interactive All-Items Checklist**](https://github.com/AsianMop/Dark-Souls-II-Completionists-Handbook/releases/latest/download/DS2-All-Items-Interactive-Checklist-Scholar-Verified.pdf)

The companion checklist contains **935 functional checkboxes** covering obtainable Scholar and Crown DLC inventory categories and covenant-progression steps, including:

- Weapons and shields
- Armour sets and standalone or alternate pieces
- Sorceries, miracles, pyromancies and hexes
- Every obtainable ring variant
- Consumables, tools, ammunition and multiplayer items
- Keys and progression items
- Upgrade materials and souls
- All nine covenant progression paths

Save a personal copy of the PDF after marking checkboxes so your progress is retained. Armour-set checkboxes represent ownership of every piece belonging to that set.

The checklist excludes cut, test and unobtainable inventory records. Gestures, achievements, world events and walkthrough objectives remain covered by the main handbook rather than the item checklist.

## Reporting Corrections

Evidence-supported corrections may be submitted through the repository’s [Issues page](https://github.com/AsianMop/Dark-Souls-II-Completionists-Handbook/issues/new/choose) or through the handbook’s Discord correction channel.

Please include:

- Handbook edition
- Version number
- Filename
- Page number
- Chapter or reference section
- Description of the suspected issue
- Supporting *Scholar of the First Sin*-specific evidence

Reports concerning the original Dark Souls II release should be clearly identified and must not be presented as Scholar-specific behaviour.

Accepted corrections will be independently checked before being incorporated into a future version.

## Verifying Downloads

Download `SHA256SUMS.txt` alongside the release files.

On Linux or macOS:

```bash
sha256sum -c SHA256SUMS.txt
```

On Windows PowerShell, calculate an individual file hash with:

```powershell
Get-FileHash ".\filename.pdf" -Algorithm SHA256
```

Compare the result with the corresponding value in `SHA256SUMS.txt`.
